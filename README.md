# Good First Issues

A curated collection of beginner-friendly open source issues to help developers start contributing to open source projects.

## Overview

Good First Issues helps developers discover open-source projects that are welcoming to new contributors. The project aggregates and showcases beginner-friendly issues from various repositories, making it easier for developers to find their first contribution opportunities.

## Features

- Discover beginner-friendly open source issues
- Explore issues from multiple repositories
- Easy-to-navigate interface
- Community-driven project
- Helps new contributors get started with open source

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

```bash
git clone https://github.com/HarshCasper/good-first-issues.git
```

2. Navigate to the project directory:

```bash
cd good-first-issues
```

3. Install dependencies:

```bash
npm install
```

4. Start the project:

```bash
npm start
```
